## ✨ Funcionalidades

- **100% responsivo** — layout adaptado para desktop, tablet e smartphone.
- **Modo claro / escuro** com detecção automática da preferência do sistema (`prefers-color-scheme`) e alternância manual persistida em `localStorage`.
- **Menu hambúrguer** acessível para navegação em telas menores.
- **Botão "voltar ao topo"** que aparece após rolagem da página.
- **HTML semântico** (`header`, `nav`, `main`, `section`, `article`, `footer`) e boas práticas de acessibilidade (`aria-*`, foco visível, `prefers-reduced-motion`).
- Sem dependências de build — basta abrir o `index.html` ou publicar em qualquer hospedagem de arquivos estáticos.

## 🎨 Identidade visual

Paleta em **tons de rosa e lilás suaves**, escolhida para transmitir empatia, afeto e humanidade — valores que a autora aplica à forma como constrói software. Tipografia combina **Fraunces** (serifada, títulos) com **Karla** (corpo do texto), via Google Fonts.

## 💻 Rodando localmente

Por não depender de nenhuma etapa de build, basta:

1. Baixar ou clonar este repositório.
2. Abrir o arquivo `index.html` diretamente no navegador,

   **ou**, para evitar eventuais bloqueios do navegador ao abrir arquivos locais, servir a pasta com um servidor simples:

   ```bash
   # Python 3
   python -m http.server 8000
   ```

   e acessar `http://localhost:8000`.
